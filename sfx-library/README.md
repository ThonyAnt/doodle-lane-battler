# Sound library

Recorded sound effects collected for Doodle Duel. Nothing here is played by the game yet: the game only loads the files in `sfx/` (see `sfx/CREDITS.md`). To use one, copy it into `sfx/` under a simple name (letters and digits only) and add it to `FILES` in `sfx.js`.

Every pack is CC0 (public domain dedication): free to use, no credit required. Sources are listed so the packs can be found again.
